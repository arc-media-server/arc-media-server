# Home, Watchlist and Playlists translation preparation (#122, Phase 2)

This phase converts Home (including its hero and Recently Added labels), Watchlist, Playlists
and playlist details. It includes the Home row editor and its administrative variant, the
playlist picker and smart-playlist forms, and their shared filter controls/summaries. English
wording, punctuation, capitalization, accessible names, DOM layout and existing user flows are
preserved apart from the explicitly reviewed singular-episode correction below.

New English namespaces: home, watchlist, playlists and filters, with shared actions in common.
There are 191 new English entries (375 across all six namespaces including the groundwork).
Counted nouns use one/other forms, inserted names use placeholders, and complete filter/sort
phrases replace concatenated English. Where existing English is invariant or awkward, this
translation pass preserves it except for the reviewed singular-episode correction below. No translated language,
language picker, Weblate setup or RTL work is included.

Built-in row names and seasonal headings follow the active language at display time. Custom
row, library, collection and playlist names remain literal, including names identical to a
built-in English label. Row IDs, saved filters and provider genre values are unchanged.
Seasonal month labels use the shared Intl formatting helper. This area's fmt.plural callers
are removed; later areas and the final helper/catalog retirement remain on #122. No dependencies,
server/API, database/migration, settings, media or provider behavior changed. CLAUDE.md and all
existing browser journeys/selectors are untouched.
