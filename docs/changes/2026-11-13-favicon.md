# Browser tab icon

The web app's tab still showed the old purple arc: `index.html` (and the two API docs pages)
drew it inline as a data URI rather than using an icon file, so swapping `icon.svg` in #452 didn't
reach the tab. They now use `/favicon.svg`, a tab-sized version of the new icon: the TV drawn with
bolder lines on a rounded black square so it still reads at 16px. A copy is in `docs/brand`.

Checks: production build, the security-headers browser spec (2 passed), and renders at 16 and
32px. No logging change.
