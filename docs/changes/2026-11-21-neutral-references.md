# Agent rules: other media servers as references only

**What changed:** the shared agent rules no longer name a particular project as a design
reference. The rule now covers every other media server and app: look at them for ideas only, and
never copy their code, artwork or exact designs. One older change note now says it looked at
"other media servers".

**Why:** the owner prefers current documents not to single out other projects. The rule itself
is unchanged in spirit and now applies more widely.

**Decisions:** history is left as it is; the repository is already public, so rewriting it would
not remove anything and would break existing clones.

**Checks:** documentation only; no code changed.

**Logging:** none needed.
