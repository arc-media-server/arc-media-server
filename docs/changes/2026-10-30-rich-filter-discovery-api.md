# Source-format filters and API discovery

Added codec, exact audio channels, dynamic range, watch-state and person filters to browsing
and saved row rules. Media constraints share a present file and appropriate stream, including
accessible series children. Unknown metadata is not inferred SDR. A typed library filter
catalog points apps to the existing facet counts. See ../FILTER-DISCOVERY-API.md for semantics,
app integration and limits. No UI, provider activity or new hot-path logging.
