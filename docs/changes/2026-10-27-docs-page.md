# API documentation page (#139, step 2, 27 October 2026)

Arc serves a readable API reference at `/docs/` (Settings › Maintenance & diagnostics ›
Diagnostics › Open API docs). It is Scalar's open-source viewer (`@scalar/api-reference`
1.74.0, MIT, pinned) built as a second Vite page (`web/docs/index.html`, `web/src/docs/main.ts`)
that reads `/api/openapi.json`; the 1.5 MB bundle loads only on that page. It makes no requests
to other hosts: telemetry, web fonts, the AI agent, MCP and Scalar's developer toolbar are off.
Scalar shows its own "Generate SDK" button only when opened at localhost/127.0.0.1 or similar.
"Try it" calls this server with the browser's session.

The generator now writes readable sidebar summaries (no leading JSON or query strings; the
handler's name when too short) and title-case groups ("Library previews"). Descriptions don't
compare Arc with Plex (owner); `TestDocsDoNotCompareWithPlex` keeps it that way, while naming a
server Arc imports from stays fine. The public docs website is on hold until the repository is
public (see #139).
