# Every profile can set its own PIN

**What changed:**
- A new **PIN** section at the top of Settings → Your profile lets any profile set a four-digit
  PIN, change it or remove it.
- Changing or removing an existing PIN needs the current one first.
- The admin can still set or reset anyone's PIN from Profiles, for a forgotten one.
- Friends sign in with their own password, so they don't get the section.
- New endpoint: `PUT /api/me/pin {"current", "pin"}`. An empty `pin` removes it. Wrong current PIN
  is 401 with `needs: "pin"`; attempts are rate-limited like profile sign-in.

**Why:** only the admin could set PINs, so people in the house couldn't lock their own profile.

**Decisions:** PIN management lives in the web app, as Plex keeps it on its website; the TV apps
already ask for PINs when switching profile.

**Checks:** `go vet ./...`, `go test ./...` (a new `TestOwnPIN` covers set, wrong current PIN,
change and remove), `go run ./tools/apidoc`, `npx tsc -b`, the production build, the i18n tests,
and a new browser journey (`web/e2e/own-pin.spec.ts`). Screenshots in
`docs/changes/2026-11-21-own-pin/`.

**Logging:** an info line when a profile changes its own PIN (profile name and whether it now has
one, never the PIN); a warning for a wrong current PIN, with the address, as for profile sign-in.
