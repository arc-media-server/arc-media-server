# Move to the arc-media-server organisation

The repository moved from `JonzaUK/arc-media-server` to `arc-media-server/arc-media-server`.

What changed:
- Live references now use the new name: `docker-compose.yml` and README (image
  `ghcr.io/arc-media-server/arc-media-server`), the Dockerfile's OCI source label, CLAUDE.md
  (clone, `gh issue list`, issue tracking), and issue links in current design docs.
- Historical notes (docs/HISTORY.md, docs/changes/*, docs/READINESS.md evidence) keep the old
  links; GitHub redirects them.
- The image name in `.github/workflows/docker.yml` already comes from the repository name, so
  pushes to main now publish `ghcr.io/arc-media-server/arc-media-server`.

Decision: the full-verification upgrade/rollback check keeps its pinned older image under
`ghcr.io/jonzauk/...`, because re-pointing it at the first organisation image would test a much
smaller upgrade. The owner grants the organisation repository read access to that package once
(docs/IMAGE-PUBLISHING.md). Without it the check fails closed rather than being skipped.

Limits: the package-access step and the owner's Unraid change can only be done by the owner, and
neither was verified from here.
