# Provider logos

TMDB and TheTVDB require their own, unmodified logos in Arc's credits. Put the official files
here, exactly as each provider supplies them, and they appear automatically (About in
Settings, and the small credit on movie and show pages). Until then the providers' names are
shown as text links.

- `tmdb.svg`: one of TMDB's approved logos, from https://www.themoviedb.org/about/logos-attribution
  (shown smaller than Arc's own branding, as TMDB requires).
- `thetvdb.svg`: TheTVDB's logo from the brand assets on https://thetvdb.com/api-information

Never recolour, stretch, crop or redraw them. `.png` also works if a provider only offers that.
